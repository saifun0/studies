## Теоретическая часть

Связный список - это линейная структура данных, узлы которой располагаются в произвольных участках памяти и связываются между собой указателями. Каждый узел односвязного списка (`struct Node`) содержит полезные данные `data` и указатель `next` на следующий узел (у последнего элемента `next == nullptr`).

Сам список хранит указатель на начало (`head`), указатель на конец (`tail`) и счетчик элементов (`count`). В отличие от массива, вставка и удаление в начале списка не требуют сдвига остальных элементов и выполняются за `O(1)`, но обращение по индексу и поиск требуют последовательного обхода от `head` за `O(n)`.

## Листинг программы

```cpp
#include <iostream>
#include <windows.h>
#include <stdexcept>

using namespace std;

// Шаблонный класс односвязного списка
template <typename T>
class SinglyLinkedList {
private:
    // Узел списка: хранит значение и указатель на следующий элемент
    struct Node {
        T data;
        Node* next;
        Node(const T& value) : data(value), next(nullptr) {}
    };

    Node* head; // указатель на первый элемент
    Node* tail; // указатель на последний элемент
    int count;  // количество элементов

public:
    // Конструктор пустого списка, сложность O(1)
    SinglyLinkedList() : head(nullptr), tail(nullptr), count(0) {}

    // Деструктор освобождает память всех узлов, сложность O(n)
    ~SinglyLinkedList() {
        clear();
    }

    // Вставка элемента в начало списка, сложность O(1)
    void push_front(const T& value) {
        Node* newNode = new Node(value);
        newNode->next = head;
        head = newNode;
        if (tail == nullptr) {
            tail = newNode;
        }
        count++;
    }

    // Удаление элемента из начала списка, сложность O(1)
    void pop_front() {
        if (head == nullptr) {
            throw underflow_error("Список пуст!");
        }
        Node* temp = head;
        head = head->next;
        delete temp;
        count--;
        if (head == nullptr) {
            tail = nullptr;
        }
    }

    // Вывод всех элементов списка, сложность O(n)
    void print() const {
        Node* curr = head;
        cout << "[";
        while (curr != nullptr) {
            cout << curr->data;
            if (curr->next != nullptr) cout << ", ";
            curr = curr->next;
        }
        cout << "]" << endl;
    }

    // Дополнительное задание (вариант 1): сумма всех элементов, сложность O(n)
    T sum() const {
        T total = T();
        Node* curr = head;
        while (curr != nullptr) {
            total += curr->data;
            curr = curr->next;
        }
        return total;
    }

    // Очистка списка с удалением каждого узла, сложность O(n)
    void clear() {
        while (head != nullptr) {
            Node* temp = head;
            head = head->next;
            delete temp;
        }
        tail = nullptr;
        count = 0;
    }

    int size() const { return count; }
    bool empty() const { return head == nullptr; }
};

int main() {
    SetConsoleOutputCP(CP_UTF8); // включаем UTF-8 в консоли Windows

    SinglyLinkedList<int> list;

    // Добавляем элементы в начало (последний добавленный станет первым)
    list.push_front(10);
    list.push_front(25);
    list.push_front(15);
    list.push_front(5);

    cout << "Список: ";
    list.print();
    cout << "Размер: " << list.size() << endl;
    cout << "Сумма элементов: " << list.sum() << endl;

    // Удаляем первый элемент
    list.pop_front();
    cout << "\nПосле pop_front: ";
    list.print();
    cout << "Новая сумма элементов: " << list.sum() << endl;

    // Проверка работы с дробными числами
    SinglyLinkedList<double> dlist;
    dlist.push_front(1.5);
    dlist.push_front(2.5);
    dlist.push_front(3.2);
    cout << "\nСписок double: ";
    dlist.print();
    cout << "Сумма double: " << dlist.sum() << endl;

    // Проверка обработки пустого списка
    SinglyLinkedList<int> emptyList;
    try {
        emptyList.pop_front();
    } catch (const exception& e) {
        cout << "\nПоймано исключение: " << e.what() << endl;
    }

    return 0;
}
```

## Анализ сложности операций

| Операция | Временная сложность | Пояснение |
| :--- | :--- | :--- |
| `push_front(value)` | `O(1)` | Создание одного узла и перестановка указателя `head` |
| `pop_front()` | `O(1)` | Сдвиг `head = head->next` и удаление старого узла |
| `print()` | `O(n)` | Проход по всем `n` узлам от `head` до `nullptr` |
| `sum()` | `O(n)` | Проход по всем `n` узлам с накоплением суммы |
| `clear()` / `~SinglyLinkedList()` | `O(n)` | Последовательное удаление каждого из `n` узлов |
| `size()` / `empty()` | `O(1)` | Чтение поля `count` или сравнение `head == nullptr` |

## Ответы на контрольные вопросы

### 1. Чем связный список отличается от динамического массива?
В динамическом массиве элементы лежат подряд в одном блоке памяти, поэтому доступ по индексу занимает `O(1)`, но вставка и удаление в начале или середине требуют сдвига элементов за `O(n)` и периодических переаллокаций. В связном списке каждый узел выделяется отдельно и хранит указатели на соседей: вставка и удаление в известном месте занимают `O(1)`, но доступ по индексу стоит `O(n)`.

### 2. Какие операции в односвязном списке выполняются за O(1)?
Вставка в начало (`push_front`), удаление из начала (`pop_front`), получение размера (`size`, если хранится счетчик), проверка на пустоту (`empty`), а при наличии указателя `tail` еще и вставка в конец (`push_back`).

### 3. Почему удаление из конца односвязного списка требует O(n) времени?
Чтобы удалить последний узел `tail`, нужно обновить указатель `next` у предпоследнего узла (сделать его `nullptr`) и перевести `tail` на него. Поскольку в односвязном списке нет ссылок назад (`prev`), приходится пройти весь список от `head` до предпоследнего узла.

### 4. Какие преимущества даёт хранение указателя tail в односвязном списке?
Указатель `tail` позволяет выполнять вставку в конец (`push_back`) за `O(1)` вместо `O(n)`, а также мгновенно получать доступ к последнему элементу списка.

### 5. Чем двусвязный список отличается от односвязного?
В двусвязном списке каждый узел хранит два указателя: `next` (на следующий узел) и `prev` (на предыдущий). За счет этого список можно обходить в обе стороны, но на каждый узел тратится память под дополнительный указатель, а операции вставки и удаления обновляют больше связей.

### 6. Какие операции в двусвязном списке выполняются быстрее, чем в односвязном?
Удаление из конца (`pop_back`) выполняется за `O(1)` вместо `O(n)`, так как предпоследний узел доступен сразу через `tail->prev`. Также быстрее удаляется произвольный узел по известному указателю (`O(1)` вместо поиска предыдущего за `O(n)`) и возможен обратный обход за `O(n)` без дополнительной памяти.

### 7. Что такое "голова" (head) и "хвост" (tail) списка?
Голова (`head`) - это указатель на первый узел списка, с которого начинается обход. Хвост (`tail`) - это указатель на последний узел списка (у которого `next == nullptr`). В пустом списке оба указателя равны `nullptr`.

### 8. Как удалить узел из середины односвязного списка?
Нужно найти узел `prev`, стоящий непосредственно перед удаляемым (`toDelete = prev->next`), перенаправить связь `prev->next = toDelete->next`, обновить `tail` (если удаляется последний элемент), после чего освободить память через `delete toDelete` и уменьшить `count`.

### 9. Как удалить узел из середины двусвязного списка? Почему это проще?
Если уже есть указатель на сам узел `node`, достаточно перепривязать соседей напрямую: `node->prev->next = node->next;` и `node->next->prev = node->prev;`, затем вызвать `delete node`. Это проще и быстрее (`O(1)`), потому что не нужно идти с начала списка в поисках предыдущего узла.

### 10. Что произойдёт, если забыть обновить tail при удалении?
Если удалить последний узел (или единственный элемент списка) и оставить `tail` указывать на уже освобожденную память, получится висячий указатель (dangling pointer). Следующий вызов `push_back` или обращение к `tail` приведет к неопределенному поведению или падению программы.

### 11. Как реализовать реверс односвязного списка?
Используют три указателя: `prev = nullptr`, `curr = head`, `next = nullptr`. В цикле `while (curr != nullptr)` запоминают `next = curr->next`, разворачивают ссылку `curr->next = prev`, и сдвигают `prev = curr`, `curr = next`. После цикла `tail = head`, а `head = prev`. Сложность `O(n)` по времени и `O(1)` по памяти.

### 12. Как обнаружить цикл в связном списке?
Применяют алгоритм Флойда ("черепаха и заяц"): два указателя стартуют с `head`, медленный шагает на один узел (`slow = slow->next`), быстрый на два (`fast = fast->next->next`). Если цикл есть, указатели обязательно встретятся (`slow == fast`); если быстрый дошел до `nullptr`, цикла нет.

### 13. В каких случаях стоит использовать список вместо массива?
Когда программа часто вставляет или удаляет элементы в начале или середине по известному итератору/указателю, размер данных сильно меняется и нежелательны переаллокации, а случайный доступ по индексу не требуется.

### 14. Какая дополнительная память требуется для каждого узла списка?
Помимо самих данных типа `T`, узел односвязного списка хранит один указатель `Node* next` (8 байт на 64-битной системе), а узел двусвязного списка два указателя `prev` и `next` (16 байт), плюс возможные накладные расходы выравнивания и аллокатора кучи.

### 15. Почему доступ по индексу в списке имеет сложность O(n)?
Узлы списка разбросаны по памяти и не образуют непрерывный блок, поэтому адрес k-го элемента нельзя вычислить формулой. Чтобы добраться до него, нужно последовательно пройти по цепочке указателей `next` ровно `k` раз, что в худшем случае требует `O(n)` шагов.
