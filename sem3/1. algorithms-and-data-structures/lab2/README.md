## Теоретическая часть

Анализ сложности оценивает, как быстро растет число операций (временная сложность) или объем памяти (пространственная сложность) при увеличении размера входных данных `n`.

О-нотация (Big O) задает верхнюю асимптотическую границу роста функции: `f(n) = O(g(n))`, если существуют положительные константы `c` и `n0`, при которых `0 <= f(n) <= c * g(n)` для всех `n >= n0`. На практике при переходе к Big O отбрасывают числовые множители и младшие слагаемые (например, `2n^2 + 100n + 1000` упрощается до `O(n^2)`).

Основные классы сложности:

| Сложность | Название | Характер роста | Пример |
| :--- | :--- | :--- | :--- |
| `O(1)` | Константная | Не зависит от `n` | Доступ к `arr[i]`, сравнение двух чисел |
| `O(log n)` | Логарифмическая | При удвоении `n` добавляется одна операция | Бинарный поиск |
| `O(sqrt(n))` | Корневая | Цикл до квадратного корня из `n` | Проверка числа на простоту |
| `O(n)` | Линейная | Пропорционально размеру входа | Линейный поиск, сумма элементов |
| `O(n log n)` | Линейно-логарифмическая | Линейный проход и деление пополам | Быстрая сортировка, сортировка слиянием |
| `O(n^2)` | Квадратичная | Два вложенных цикла по `n` | Пузырьковая сортировка |
| `O(2^n)` | Экспоненциальная | Удваивается на каждый новый элемент | Наивная рекурсия Фибоначчи |

Шаблоны (`template <typename T>`) позволяют описать функцию или класс один раз без привязки к конкретному типу данных. При компиляции компилятор сам подставляет нужные типы (`int`, `double`, `char`, `string`) и генерирует соответствующий код.

## Определение сложности фрагментов кода

Ниже приведен разбор типовых алгоритмических фрагментов из базового уровня:

| Фрагмент кода | Сложность | Обоснование |
| :--- | :--- | :--- |
| `return (a > b) ? a : b;` | `O(1)` | Выполняется одно сравнение независимо от каких-либо объемов данных |
| `for (int i = 0; i < n; i++) sum += arr[i];` | `O(n)` | Один проход по `n` элементам, внутри цикла операция `O(1)` |
| `for (int i = 1; i < n; i *= 2) count++;` | `O(log n)` | На каждом шаге `i` удваивается, всего около `log2(n)` итераций |
| `for (int i = 0; i * i < n; i++) count++;` | `O(sqrt(n))` | Счетчик растет на 1, но цикл заканчивается при `i = sqrt(n)` |
| Внешний `for (i = 0; i < n; i++)`, внутри `for (j = n; j > 0; j /= 2)` | `O(n log n)` | Внешний цикл делает `n` шагов, на каждый из них внутренний делит `j` пополам за `log2(n)` шагов |
| Два вложенных цикла `i` от `0` до `n` и `j` от `0` до `n` | `O(n^2)` | На каждую из `n` итераций внешнего цикла выполняется `n` итераций внутреннего |

## Листинг программ

### Базовый уровень (`part1_basic.cpp`)

Имя `getMax` выбрано вместо `max`, чтобы избежать конфликта неоднозначности со стандартной функцией `std::max` при подключенном `using namespace std;`.

```cpp
#include <iostream>
#include <windows.h>
#include <string>

using namespace std;

// Шаблонная функция поиска максимума из двух значений (сложность O(1))
template <typename T>
T getMax(T a, T b) {
    return (a > b) ? a : b; // если a > b, вернуть a, иначе b
}

int main() {
    SetConsoleOutputCP(CP_UTF8); // включаем UTF-8 в консоли Windows

    // Демонстрация работы шаблона с разными типами данных
    cout << getMax(1, 2) << endl;       // int
    cout << getMax(1.11, 2.22) << endl; // double
    cout << getMax('a', 'z') << endl;   // char

    // Сравнение строк (std::string, а не const char*)
    string s1 = "aa";
    string s2 = "a";

    cout << getMax(s1, s2) << endl;

    return 0;
}
```

### Средний уровень (`part2_medium.cpp`)

```cpp
#include <iostream>
#include <windows.h>
#include <string>

using namespace std;

// Шаблонный класс для хранения пары значений произвольных типов T1 и T2
template <typename T1, typename T2>
class Pair {
private:
    T1 first;
    T2 second;

public:
    // Конструктор: инициализация двух полей, сложность O(1)
    Pair(const T1& f, const T2& s) : first(f), second(s) {}

    // Геттеры: чтение полей, сложность O(1)
    T1 getFirst() const { return first; }
    T2 getSecond() const { return second; }

    // Сеттеры: запись новых значений, сложность O(1)
    void setFirst(const T1& f) { first = f; }
    void setSecond(const T2& s) { second = s; }

    // Вывод пары в консоль, сложность O(1)
    void print() const { cout << first << ", " << second << endl; }
};

int main() {
    SetConsoleOutputCP(CP_UTF8); // включаем UTF-8 в консоли Windows

    // Создание пар с разными комбинациями типов
    Pair<string, int> p1("Возраст", 18);
    Pair<int, double> p2(20, 13.2);
    Pair<int, string> p3(13, "книг");

    p1.print();
    p2.print();
    p3.print();

    // Изменение значений через сеттеры
    p1.setFirst("Количество");
    p1.setSecond(20);

    p1.print();

    // Проверка работы геттеров
    cout << p1.getFirst() << " " << p1.getSecond() << endl;

    return 0;
}
```

## Анализ сложности реализованных операций

| Операция | Временная сложность | Пространственная сложность | Пояснение |
| :--- | :--- | :--- | :--- |
| `getMax(a, b)` | `O(1)` | `O(1)` | Одно сравнение `a > b` (для строк `std::string` сравнение зависит от длины строки `O(L)`) |
| `Pair(f, s)` | `O(1)` | `O(1)` | Инициализация двух фиксированных полей `first` и `second` |
| `getFirst()` / `getSecond()` | `O(1)` | `O(1)` | Прямой возврат значения поля |
| `setFirst(f)` / `setSecond(s)` | `O(1)` | `O(1)` | Прямое присваивание полю |
| `print()` | `O(1)` | `O(1)` | Вывод двух полей в стандартный поток |

## Ответы на контрольные вопросы

### 1. Что такое О-нотация (Big O) и зачем она нужна?
О-нотация описывает верхнюю границу скорости роста времени работы или расхода памяти алгоритма при увеличении объема входных данных `n`. Она нужна, чтобы сравнивать алгоритмы между собой независимо от мощности компьютера, компилятора и языка программирования.

### 2. Какая сложность у доступа к элементу массива по индексу? Почему?
Сложность `O(1)`. Элементы массива лежат в памяти подряд, поэтому адрес нужного элемента вычисляется одной арифметической формулой (`адрес_начала + индекс * размер_элемента`) без перебора.

### 3. Какая сложность у бинарного поиска? Почему?
Сложность `O(log n)`. На каждом шаге алгоритм сравнивает искомое значение со средним элементом отсортированного массива и отбрасывает половину оставшегося диапазона. Чтобы сократить `n` элементов до одного, нужно максимум `log2(n)` делений пополам.

### 4. Что означает сложность O(n log n)? Приведите пример алгоритма.
Она означает, что при увеличении данных время растет чуть быстрее линейного (пропорционально произведению `n` на `log n`). Классические примеры: сортировка слиянием (Merge Sort), быстрая сортировка (Quick Sort в среднем случае) и пирамидальная сортировка (Heap Sort).

### 5. Что такое амортизированный анализ? Приведите пример.
Это оценка средней стоимости одной операции на длинной последовательности вызовов, когда большинство операций дешевые, а редкие обходятся дорого. Пример: `push_back` в `std::vector`. Обычно вставка в конец стоит `O(1)`, но когда место заканчивается, вектор удваивает емкость и копирует элементы за `O(n)`. В пересчете на все вставки средняя (амортизированная) сложность одного `push_back` остается `O(1)`.

### 6. Какая сложность у двух вложенных циклов по n итераций каждый?
Сложность `O(n^2)`: для каждой из `n` итераций внешнего цикла внутренний выполняется `n` раз, что дает `n * n` операций.

### 7. Какая сложность у рекурсивного вычисления чисел Фибоначчи?
У наивной рекурсии `fib(n) = fib(n - 1) + fib(n - 2)` сложность экспоненциальная, `O(2^n)`, потому что каждый вызов порождает два новых и одни и те же подзадачи пересчитываются много раз.

### 8. Что такое шаблоны функций? Как их объявить и использовать?
Шаблон функции описывает общий алгоритм с параметром-типом, чтобы не дублировать одинаковый код для разных типов. Объявляется через `template <typename T>` перед заголовком функции:

```cpp
template <typename T>
T getMax(T a, T b) {
    return (a > b) ? a : b;
}
```

При вызове `getMax(1, 2)` или `getMax(1.5, 2.3)` компилятор сам выводит тип `T`.

### 9. Что такое шаблоны классов? Как их объявить и использовать?
Шаблон класса позволяет параметризовать типы полей и методов класса. Объявляется с `template <typename T1, typename T2>` перед `class`:

```cpp
template <typename T1, typename T2>
class Pair {
    T1 first;
    T2 second;
};
```

При создании объекта типы указывают в угловых скобках: `Pair<string, int> p("Возраст", 18);`.

### 10. В чём преимущество шаблонов перед перегрузкой функций?
При перегрузке приходится вручную писать и потом поддерживать отдельную копию функции для каждого типа (`int`, `double`, `char`, `string`). Шаблон пишется один раз, устраняет дублирование кода и сразу работает с любым типом, который поддерживает нужные операции (например, `>`).

### 11. Как указать, что шаблонный параметр - тип?
Внутри угловых скобок после `template` пишут `typename ИмяТипа` или `class ИмяТипа` (например, `template <typename T>`). В этом контексте `typename` и `class` означают одно и то же.

### 12. Можно ли создать шаблон с несколькими параметрами типов?
Да, их перечисляют через запятую внутри `template <...>`. Именно так в работе реализован `Pair`: `template <typename T1, typename T2>`.

### 13. Как провести экспериментальное измерение времени выполнения?
В C++ используют библиотеку `<chrono>`: сохраняют отметку времени `high_resolution_clock::now()` до запуска алгоритма и сразу после, а затем вычитают их через `duration_cast<microseconds>(end - start).count()`.

### 14. Почему при измерении времени нужно выполнять операцию многократно?
Быстрые операции (вроде бинарного поиска или обращения к `Pair`) выполняются за наносекунды, что меньше точности системного таймера, и одиночный замер часто дает 0 мкс. Многократный запуск в цикле сглаживает случайные колебания нагрузки ОС и позволяет получить стабильное измеримое время.

### 15. Что важнее: сложность алгоритма или константа?
На больших объемах данных важнее асимптотическая сложность: алгоритм `O(log n)` или `O(n)` с большой константой все равно обгонит `O(n^2)` с маленькой константой, когда `n` вырастет. Константа начинает играть заметную роль только на небольших массивах или при сравнении двух алгоритмов с одинаковой асимптотикой.
